# Мұра — product UI
No landing page, mission, marketing or explainer sections. Default route is catalog. NIS-inspired typography and spacious restrained structure; white and graphite, orange actions. Manrope, thin gray borders, modest 5px radii. Dark mode and RU/KZ/EN preserved.
Desktop application header: brand, search, saved, chats, bookings, account; compact section navigation. Catalog with filter chips, category sidebar, product grid. Mobile five-item bottom navigation. Item page with write/reserve/save and QR. Chats: two-panel inbox, item context, timestamped messages and image attachments. Profile contains personal settings and listings only.
API: Better Auth email/password, server sessions; Drizzle database tables for listings, bookmarks, conversations, messages, reservations, history. Authenticated access scoped to participants and owners. Sample listings stored in database and clearly marked DEMO, cannot message fictional owners. No simulated responses. Server role checks for moderation. No outgoing emails, payments or automatic CO2.
Files: api/auth.ts, middleware/auth.ts, database/schema.ts, routes/market.ts and chats.ts; web/pages/product.tsx, components/product-chats.tsx, lib/auth.ts, queries/market.ts. Previous demo data in browser is not migrated to real accounts.
